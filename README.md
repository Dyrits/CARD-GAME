# Card Game

A card game application in Java, built for the OpenClassrooms course "Use MVC, SOLID Principles, and Design Patterns in Java".

## About The Project

The course covers writing quality Java code following the SOLID design principles and the model-view-controller (MVC) design pattern, incorporating them into an ever-improving application, along with other design patterns. This repository contains the card game application built along the course.
